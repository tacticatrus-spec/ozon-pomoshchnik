# OZON Assistant

Версия 0.5.2: SEO-контроль сразу для TT-P, ZV и TT-L. Программа формирует отдельные поисковые запросы по каждой карточке, открывает общую выдачу Ozon и сохраняет проверенные позиции с датой. Рекомендации не отправляются в Ozon автоматически.

Версия 0.5.1: фотографии рядом с товарами и открытие полного изображения по нажатию. После обновления синхронизируйте каталог для загрузки фотографий.

Версия 0.5.0 добавляет **Защитник прибыли**. Он показывает точку безубыточности, безопасную цену с учётом целевой маржи и предупреждает о товарах в убытке. Себестоимость и целевая маржа сохраняются только на компьютере продавца и не передаются в Ozon.

Локальная программа для Windows, работающая через официальный Ozon Seller API.

## Возможности

- каталог товаров, текущие цены и остатки;
- ручная себестоимость и предварительный расчёт прибыли;
- локальные правила себестоимости по началу артикула;
- отдельные цены продавца и покупателя из ответа Ozon;
- точка безубыточности, безопасная цена и фактическая маржа по каждому товару;
- статусы «в убытке», «ниже маржи», «нет себестоимости» и «безопасно»;
- локальная настройка целевой маржи и Telegram-предупреждение при изменении рисков;
- предложение новой цены с ограничением по минимальной марже;
- изменение цены только после явного подтверждения;
- FBS/FBO-заказы;
- отзывы и вопросы, подготовка и отправка ответов;
- Telegram-уведомления;
- демонстрационный режим без ключей Ozon.
- поиск фразы в характеристиках всех карточек и массовая замена после предварительного просмотра и подтверждения;
- отдельный список товаров и имён видеофайлов, которые Ozon не разрешает переименовывать через API.
- SEO-аудит карточек TT-P, ZV и TT-L с безопасным предварительным просмотром;
- фиксация места карточки по каждому поисковому запросу и история наблюдений;
- прямое открытие общей поисковой выдачи Ozon без фильтра продавца.

## Запуск на Windows 10/11

1. Установите Python 3.11 или новее с сайта python.org. При установке отметьте **Add Python to PATH**.
2. Дважды нажмите `run.bat`.
3. Откроется страница `http://127.0.0.1:8765`.
4. В разделе «Настройки» введите Client ID и API Key из кабинета Ozon Seller.
5. Сначала нажмите «Проверить подключение», затем «Синхронизировать».

## Обновления

Начиная с версии 0.3.0 программа проверяет обновления при запуске и затем каждые пять минут. Когда новая версия доступна, откройте «Настройки» → «Обновления» и нажмите «Установить обновление». Программа обновится и перезапустится, при этом локальная база, себестоимость и ключи останутся на компьютере.

Секреты сохраняются в хранилище учётных данных Windows через библиотеку Keyring. Они не записываются в базу программы.

## Telegram

Создайте бота через `@BotFather`, получите токен, напишите своему боту любое сообщение. В настройках программы укажите токен и Chat ID. Узнать Chat ID можно через кнопку в интерфейсе после отправки сообщения боту.

## Важно

- При первой синхронизации не включается автоматическое изменение цен.
- Защитник прибыли ничего не отправляет в Ozon и сам не меняет цены.
- Новая цена отправляется в Ozon только после кнопки подтверждения.
- Массовая замена характеристик сначала показывает найденные товары и отправляется только после отдельного подтверждения.
- Прибыль в панели является управленческой оценкой. Точный итог зависит от комиссий, логистики, возвратов, рекламы и прочих начислений Ozon.
- Некоторые методы (включая отзывы, вопросы и конкурентные стратегии) могут требовать соответствующей роли API-ключа или быть недоступны на конкретном тарифе.
